# Veyranta — AI Reputation & Customer Intelligence Platform

Veyranta is an AI-powered reputation management and customer intelligence platform built with Next.js 14, React 18, Tailwind CSS, and Razorpay payment gateway integration.

## 🚀 Key Features

- **Rare Amethyst-Violet UI Theme**: Modern design with glassmorphism and smooth micro-interactions.
- **Light & Dark Mode Switcher**: Seamless theme toggling persisted in browser local storage.
- **Multi-Currency Billing Switcher**: 1-click toggle between INR (₹), USD ($), and EUR (€).
- **Multi-Source Customer Signal Scanner**: Customer review analysis, sentiment score, 12-tone emotional spectrum, and recurring issue clusters.
- **SSRF & Security Protection**: Domain mismatch protection preventing deceptive scans.
- **Instant Scan Fallback Engine**: Dual server & client fallback ensuring < 1.5 second analysis response time.
- **Razorpay Live & Test Gateways**: Production-ready HMAC-SHA256 signature verification.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Lucide Icons
- **Payments**: Razorpay Node SDK & Client API
- **AI Processing**: Embedded Customer Sentiment & Emotion Pipeline

## 🏁 Getting Started

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build production bundle
npm run build
```
